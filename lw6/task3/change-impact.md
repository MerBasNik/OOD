# Задание 3

## Добавление слоев

### Затронутые компоненты

#### `Document`, `IShape`, `Timeline`

**as-is**

В документе один список фигур/групп. Поиск верхней фигуры учитывает порядок, вложенность и время
[Document](../../Editor/Model/Document/Document.cpp)

**to-be**

Хранить в документе список слоев с id, именем, состоянием видимости и последовательностью фигур.
Каждая фигура принадлежит одному слою. Перенос меняет только принадлежность и порядок

#### `EditorWindow`, `CanvasView`

**as-is**

Окно показывает текущее состояние и распределяет ввод между холстом и панелями
[EditorWindow](../../Editor/View/Window/EditorWindow.cpp),
[Canvas](../../Editor/View/Canvas/CanvasView.cpp),
[ShapeListView](../../Editor/View/ShapeList/ShapeListView.cpp)

**to-be**

Расширить список фигур строками слоев. В строке слоя разместить кнопку видимости (глазик), в
панели - кнопки создания слоя и переноса. Скрытый слой остается в списке, чтобы его можно было
показать снова. Canvas будет рисовать видимые слои и учитывать текущий момент времени

#### `EditorController`, `ShapeListController`, `EditorState`

**as-is**

Используется превью состояние для показа не закоммиченных изменений и общее состояние документа для
отображения всего остального
[EditorState](../../Editor/Model/EditorState/EditorState.h),
[ShapeListController](../../Editor/Controller/ShapeListController.cpp)

**to-be**

Хранить id активного слоя в состоянии окна, чтобы новые фигуры попадали в выбранный пользователем
слой. Контроллер должен учитывать видимость слоя при выборе, в том числе при проверке рамки
выделенной фигуры

#### `ICommand`, `CommandHistory`

**as-is**

Команда запоминает нужные данные, история выполняет команду, сохраняет ее, вызывает undo или redo
[History](../../Editor/Command/CommandHistory/CommandHistory.cpp)

**to-be**

Для переноса сохранить id фигуры, исходный и целевой слои, позиции в обоих слоях. Один перенос
образует одну запись истории. Доработать команды добавления, удаления, группировки и тд там, чтобы
учитывать слой

#### `TimelineView`, `TimelineController`

**as-is**

Работают с теми же состояниями, что и окно редактирования
[TimelineView](../../Editor/View/Timeline/TimelineView.cpp),
[TimelineController](../../Editor/Controller/TimelineController.cpp)

**to-be**

Получать из модели одинаковую последовательность id для показа и обработки ввода. При скрытии слоя
скрывать строки фигур на этом слое, а при показе слоя снова показывать

#### `DocumentSerializer`

**as-is**

Файл содержит последовательность фигур/групп с характеристиками
[AppWindow](../../Editor/Application/AppWindow.cpp),
[DocumentSerializer](../../Editor/Model/Serialization/DocumentSerializer.cpp)

**to-be**

При сохранении в файл можно использовать тот же подход, что и с группами - добавлять ключевые слова:
startLayer и endLayer, а рядом записывать информацию о них

### to-be

1. Создание. Пользователь выбирает фигуры, нажимает "Создать слой" и вводит имя для слоя.
   Панель передает действие контроллеру. Создается команда и сохраняется в истории команд
   Модель добавляет слой и уведомляет окна. Созданный слой выделяется
2. Видимость. Пользователь нажимает на кнопку "Показать слой/Скрыть слой". Контроллер передает
   изменение слоя в модель. Холст показывает/скрывает выделенный холст, то есть то, что было на этом
   слое показывается/скрывается, а также показывается/скрывается timeline
3. Перенос. Пользователь выбирает слой в списке и перетаскивает слой в нужное место. Контроллер
   создает команду переноса, выполняет ее и сохраняет в историю команд
   [Существующий механизм записи](../../Editor/Command/CommandHistory/CommandHistory.cpp),
   [Завершение обновления модели](../../Editor/Model/Document/Document.cpp)
4. Undo и Redo. При Undo история вызывает отмену переноса. Если в истории была команда создания, то
   происходит удаление слоя без удаления фигур на ней. Если была команда переноса. то выполняется
   перенос на старую позицию
   [Механизм Undo и Redo](../../Editor/Command/CommandHistory/CommandHistory.cpp)

### Вопросы и риски

1. Добавить видимое отображение слоев в списке фигур и timeline
2. Предусмотреть выбор фигур из разных слоев, а также запретить возможность выбора фигуры при
   выключенном слое
3. Предусмотреть скрытие timeline, когда слой скрыт
4. Нужно ли сразу сохранять в модель видимость слоев? Какое будет поведение слоев при работе в
   нескольких окнах?
5. Доработать сохранение слоев в файл и загрузку из файлов
