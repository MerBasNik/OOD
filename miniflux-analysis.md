| Обоснование                                                           | Подтверждение                                                                                                                                                                                                                                                                          |
|-----------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Выделена отдельная роль пользователя                                  | В методе showUnreadPage есть вызов request.UserID(r), который определяет пользователя, для которого делается поиск записей через NewEntryQueryBuilder(user.ID) [Ссылка](../internal/ui/unread_entries.go#L15-L34)                                                                      |
| Выделена отдельная роль администратора                                | В методе saveUser проверяется user.IsAdmin. При отсутствии права он вызывает response.HTMLForbidden и завершает обработку. Для администратора доступно создание пользователя h.store.CreateUser [Ссылка](../internal/ui/user_save.go#L21-L65)                                          |
| Серверная часть Miniflux сама запрашивает новые статьи                | Есть функция RefreshFeed, которая отправляет запрос и передает ответ в parser.ParseFeed [Ссылка](../internal/reader/handler/handler.go#L251-L295)                                                                                                                                      |
| Серверная часть сама формирует HTML-страницы для показа пользоватеялм | Есть метод showUnreadPage, который передает записи в шаблон через view.Set, формирует страницу вызовом view.Render("unread_entries") и отправляет ее через response.HTML [Ссылка](../internal/ui/unread_entries.go#L55-L65)                                                            |
| Для базового сценария не нужен отдельный сервис OAuth2                | Потому что метод checkLogin вызывает h.store.CheckPassword, который получает хеш пароля из таблицы users и проверяет введенный пароль через bcrypt.CompareHashAndPassword [Ссылка](../internal/ui/login_check.go#L52-L59) и [Ссылка](../internal/storage/user.go#L672-L690)            |
| База данных использует PostreSQL                                      | Функция database.NewConnectionPool открывает пул через sql.Open("postgres", dsn). В basic.yml у сервиса db указан образ postgres:18 [Ссылка](../internal/database/postgresql.go#L14-L22) и [Ссылка](../contrib/docker-compose/basic.yml#L21-L28)                                       |
| База данных изображена как отдельная система                          | В basic.yml сервис db имеет собственный том miniflux-db. Приложение получает адрес базы через config.Opts.DatabaseURL() и передает его в database.NewConnectionPool [Ссылка](../contrib/docker-compose/basic.yml#L21-L36) и [Ссылка](../internal/cli/cli.go#L157-L168)                 |
| Клиентская часть выделена в отдельную систему                         | Метод showUnreadPage возвращает готовый HTML, а в браузере функция initializeClickHandlers регистрирует обработчики действий, которые выполнениют клиентский код в браузере [Ссылка](../internal/ui/unread_entries.go#L55-L65) и [Ссылка](../internal/ui/static/js/app.js#L1255-L1263) |
